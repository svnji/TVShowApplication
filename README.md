# 📺 TV Show Application

A simple iOS application built with **UIKit** that allows users to browse TV shows, explore detailed information, and discover popular series through an intuitive interface.

This project was created as one of my early iOS learning projects and demonstrates the fundamentals of iOS development, networking, and UI design.

## ✨ Features

* Browse TV Shows
* View Show Details
* Search for TV Shows
* Display Posters & Images
* Responsive User Interface
* API Integration

---

## 🛠 Tech Stack

* Swift
* UIKit
* MVC / MVVM
* URLSession
* CocoaPods
* JSON Decoding
* Auto Layout

## 🚀 Getting Started

### Requirements

* Xcode
* CocoaPods

### Installation

```bash
git clone https://github.com/svnji/TVShowApplication.git
cd TVShowApplication
pod install
open TVShowApplication.xcworkspace
```
